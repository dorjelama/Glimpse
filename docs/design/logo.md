# Logo Guidelines — Glimpse Design System

## Clear Space

Minimum clear space must be maintained on **all four sides** of the logo at all times.

```
Unit: 1× cap height of the wordmark

         ┌ ─ ─ ─ ─ ─ ─ ─ ─ ─ ─ ─ ─ ─ ─ ─ ┐
                      1× cap height
         │  ┌───────────────────────────┐  │
            │                           │
1× cap   │  │        GLIMPSE LOGO       │  │  1× cap
height      │                           │    height
         │  └───────────────────────────┘  │
                      1× cap height
         └ ─ ─ ─ ─ ─ ─ ─ ─ ─ ─ ─ ─ ─ ─ ─ ┘
```

**Rule:** Never place any other element — text, icon, image, border, or background edge — within the dashed exclusion zone.

---

## How to Measure Cap Height

Cap height is the height of a flat-topped uppercase letter (e.g. **H**) in the wordmark at its rendered size. As the logo scales, the clear space scales with it proportionally.

---

## What Counts as a Violation

- Another logo or brand mark overlapping the zone
- Body text or UI labels entering the zone
- A card edge, image crop, or container boundary clipping into the zone
- Decorative elements (rules, icons, patterns) inside the zone

---

## Minimum Size

| Context | Minimum width |
|---------|--------------|
| Digital (screen) | 80 px |
| Print | 20 mm |

Below these sizes, switch to the icon-only mark if available.

---

## Placement on Backgrounds

| Background | Preferred logo variant |
|------------|----------------------|
| Cream `#F6EBDD` | Full-color (default) |
| Ink `#1E130C` | Reversed / light variant |
| Terra `#B85C37` | Light variant only |
| Photography / busy image | Use logo on a Cream or Ink lockup |
